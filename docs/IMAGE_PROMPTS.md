# Kreomax image prompts

Each prompt below is complete. Copy one block, paste it into your image tool, and generate.
Always do **Step 0 first**, then attach the character sheet as a reference image for all others
so the same kids and robot appear everywhere.

Rules for all images: original characters only (no real people, no existing characters or brands),
no text or logos in the image, soft pastel lilac look, transparent or plain white background.

Save the results to `frontend/public/images/` using the filenames shown.
